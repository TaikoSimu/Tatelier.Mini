### 音符文字(#SENOTECHANGE)を表示する場合

一般的な太鼓さん次郎のリソースパックに含まれる`img/senotes.png`は、実際の文字幅が不揃いな凡例・資料用の画像で、音符文字の描画には使用できません。

`#SENOTECHANGE`で指定される「ドン」「カッ」などの音符文字を表示するには、別途`img/notetext.png`を用意して同じ`img`フォルダに置いてください。139×297pxのように高さを9等分できる縦積みスプライトシートで、上から「どん・ど・こ・かっ・か・連打・げき連打・(空欄)・(空欄)」の順に並んでいる必要があります。このファイルが無い場合、音符文字は表示されません(それ以外の演奏には影響ありません)。
